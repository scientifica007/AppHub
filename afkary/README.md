# أفكاري — Afkary

تطبيق ويب عربي (RTL) لحفظ الفكرة بصيغتها الخام **حرفيًا** ثم إنشاء طبقات منفصلة لفهرستها وتنظيمها واستكشاف إمكانات تطويرها، دون تعديل نصها الأصلي.

## المبادئ غير القابلة للتنازل

1. **الفكرة الأصلية ثابتة:** تُخزَّن كما أُدخلت، بما في ذلك المسافات والأسطر. لا توجد واجهة لتعديل سجل أصلي محفوظ. لكل فكرة معرف وتاريخ حفظ وبصمة SHA-256 للكشف عن التغييرات العرضية؛ البصمة ليست توقيعًا رقميًا موثوقًا ضد العبث المتعمد.
2. **التنظيم مستقل:** تُستخرج عناوين عرض، وتصنيفات وكلمات مفتاحية من النص. تعديل التصنيف يُحفظ في سجل annotations منفصل. العنوان المختصر ليس بديلًا عن النص الأصلي.
3. **الاقتراحات مستقلة:** أسئلة تطوير واختبار نقدي حسب المجال مستمدة من قواعد محلية، وليست إجابات مولَّدة بنموذج لغوي. الروابط بين الأفكار تعتمد التشابه اللفظي، وتُعرض بوصفها اقتراحات أولية لا حقائق.
4. **الخصوصية افتراضيًا:** لا رفع إلى GitHub، ولا تخزين سحابي، ولا تحليلات، ولا تعقب، ولا API خارجي. يحفظ IndexedDB النصوص على جهازك في متصفحك وأصل الموقع هذا فقط. التطبيق العام لا يعني أن الأفكار المنشأة فيه عامة.
5. **استعادة البيانات:** تصدير ملف JSON يحوي النصوص والبيانات المشتقة المنفصلة. يتحقق الاستيراد من البصمات ويمنع استبدال فكرة محفوظة بمعرّفها ذاته. الاستيراد يضيف السجلات الجديدة فقط ولا يستبدل الملاحظات الموجودة.

## الوظائف في النسخة الأولى

- التقاط فكرة دون اشتراط عنوان أو تصنيف أو تنسيق.
- فهرسة آلية أولية حسب مجالات متنوعة، وسوم، بحث عربي يتسامح مع التشكيل والهمزات.
- استخراج روابط بين الأفكار عند تشابه الكلمات الأساسية.
- اقتراح أسئلة وآفاق تطوير مرتبطة بمجال كل فكرة.
- تصحيح التصنيف، تمييز الأفكار، وإضافة ملاحظات مستقلة عن النص الأصلي.
- تصدير واستيراد نسخ احتياطية JSON، مع تحقق SHA-256.
- واجهة عربية RTL متجاوبة تعمل دون إطار عمل أو خدمة خلفية.

## التشغيل المحلي

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000/`. التشغيل عبر `file://` غير مدعوم. اختبارات القواعد:

```bash
npm run check
npm test
```

## حدود مهمة

- **البيانات مرتبطة بالمتصفح والجهاز واسم نطاق الموقع:** لن تظهر الأفكار آليًا على جهاز آخر، ولا بين `localhost` وGitHub Pages. استعمل التصدير والاستيراد للنقل.
- حذف بيانات المتصفح، أو الوضع الخاص، أو تغيير أصل النطاق قد يؤدي إلى فقدان الوصول إلى الأفكار. يجب الاحتفاظ بنسخ احتياطية خارج المتصفح، ويفضل في وسيط مشفر.
- النصوص الحساسة غير مشفّرة عند الراحة بواسطة التطبيق نفسه، ولا يجب اعتبار IndexedDB خزنة أسرار. تشفير محلي بمفتاح المستخدم، ومزامنة اختيارية آمنة، واسترجاع محكم، مراحل مستقبلية مستقلة.
- التحليل الحالي **قائم على قواعد**، وليس ذكاء اصطناعيًا توليديًا. التحليل اللغوي المتقدم لاحقًا يجب أن يكون اختياريًا ومشروطًا بموافقة صريحة على إرسال النصوص إلى خادم عند استخدام خدمة سحابية.
- التصميم يجعل سجلات المصدر غير قابلة للتعديل من واجهة التطبيق؛ لا يضمن عدم العبث من خلال أدوات المطور أو الملفات المحلية.

## بنية البيانات

`entries`: `{ id, raw, createdAt, checksum }` — لا تُستبدل سجلاتها.

`annotations`: `{ id, categoryOverride, note, favorite }` — قابلة للتعديل استقلالًا.

المخرجات الآلية (`derived index`) تُعاد حسابها من النص الأصلي محليًا دون إعادة كتابة السجل. لاحقًا يمكن إضافة سجل تاريخي لتحولات التحليل مع إصدارات المحرك دون تغيير الأصول.


## النسخة 0.2.0 — ثيمات ومعرض أفقي

- صفحة مستقلة `gallery.html` تعرض الأفكار ببطاقات أفقية قابلة للتمرير، مع فرز حسب الأحدث والأقدم والأبجدية صعودًا ونزولًا أو حسب التصنيف، وتصفية حسب الموضوع وبحث محلي.
- خمس ثيمات: فحمي، ورقي، شفق، سماء ليلية، واحة. الثلاث الأخيرة تحتوي صور SVG أصلية محلية متعددة الطبقات لعمق بصري، ولا تتصل بالإنترنت لجلبها.
- اختيار المظهر محفوظ محليًا في `localStorage` ويطبّق على الصفحتين، دون دخول إلى قاعدة الأفكار.
- الضغط على أي بطاقة يعرض النص الخام كاملاً للقراءة فقط، والرابط إلى واجهة تحليل الفكرة نفسها.
- الفرز والعرض لا يعيدان كتابة قاعدة IndexedDB، ولا يغيران تنسيق النسخة الاحتياطية.

الصور رسومات متجهية (SVG) وليست صورًا فوتوغرافية. لا تتضمن أي مكتبة أو ملفات تتبع من طرف ثالث.

## النسخة 0.3.0 — أرشيف عمودي، توقيت دقيق، تركيز

- إضافة `list.html`: قائمة أفكار **عمودية**، تعرض النص الأصلي كاملًا في بطاقات متتالية؛ نفس البحث والتصفية وخيارات الفرز في المعرض الأفقي، دون أي إعادة كتابة للسجلات.
- في جميع العروض يظهر **التاريخ والساعة والدقيقة والثانية** بصيغة `dd/mm/yyyy · HH:mm:ss` وفق المنطقة الزمنية المحلية للجهاز. الطابع الزمني الأصلي `createdAt` موجود أصلاً بدقة أجزاء الثانية بصيغة UTC، ولا يتغيّر. التاريخ هو وقت إنشاء سجل الحفظ قبل إتمام المعاملة مباشرة، لا وقت الضغط الفيزيائي المقاس خارجيًا.
- زر إظهار/إخفاء شريط التنقل في صفحة الالتقاط، مع حفظ خيار الواجهة محليًا فقط؛ يعيد إظهار الشريط متى طلب المستخدم.
- زر «عدم التشويش»: يحجب كافة المعلومات والأيقونات الثانوية ويمنح خلفية بيضاء هادئة ومساحة كتابة كبيرة، مع إبقاء السؤال «ما الذي يدور في ذهنك؟» وزر الحفظ وإمكانية الخروج. يحتفظ التطبيق بالمظهر المختار سابقًا ويعيده عند الخروج.
- الإعدادات البصرية في `localStorage`، والنصوص والبيانات المشتقة في `IndexedDB` دون تغيير، ولا يتغير `schemaVersion: 1` للنسخ الاحتياطية.

## v0.4.0 — أرشيف موحد، إملاء صوتي، تنظيم شخصي، استعادة ومراجعات

- **الأرشيف الموحد:** `archive.html` يجمع ثلاثة أوضاع: أفقي، عمودي، وشبكي RTL (بطاقات من اليمين إلى اليسار ومن سطر إلى الذي يليه). يحتفظ `gallery.html` و`list.html` بروابط الانتقال المتوافقة مع الصفحات السابقة.
- **الإملاء الصوتي المباشر:** خيار بدء/إيقاف باستخدام Web Speech API، باللغة `ar-DZ` ونتائج مؤقتة تظهر أثناء الكلام. تظل مراجعة النص وحفظه خطوة صريحة. يعتمد على دعم المتصفح وقدرة محرك التعرف لديه؛ الصوت **قد يُرسل إلى خدمة خارجية تابعة للمتصفح**. لا يوفر التطبيق نفسه خادمًا لمعالجة الصوت.
- **مجلدات وتصنيفات شخصية اختيارية:** إنشاء أسماء مخصصة وإلحاقها بالفكرة من لوحة تفاصيلها. يظل التصنيف الآلي مفعّلًا افتراضيًا؛ التصنيف الشخصي طبقة مستقلة.
- **تعقيبات:** سجل تعليقات منفصل لكل فكرة؛ لا يتدخل في النص الأصلي.
- **مراجعات النص:** كل حفظ تعديل ينشئ سجل `revisions` ببصمته وتوقيته ورابط البصمة السابقة، مع بقاء `entries.raw` محفوظًا كما كان. يعرض التطبيق النص الحالي ويتيح الرجوع إلى الأصل والمراجعات السابقة؛ لا توجد عملية استبدال مباشرة للأصل.
- **سلة مهملات:** نقل محمي بتأكيد، واستعادة تحفظ المراجعات والتعليقات. الحذف النهائي من داخل السلة فقط، ويتطلب كتابة `حذف نهائي` ثم تأكيدًا ثانيًا. لا يوجد تنظيف تلقائي للسلة.
- **قاعدة بيانات v2:** ترقيات IndexedDB تضيف مخازن جديدة دون نسخ أو تعديل المخزنين الأصليين `entries` و`annotations`. يدعم استيراد نسخ JSON v1، ويصدر v2 متضمنًا جميع البيانات الجديدة، ويتحقق من البصمات قبل الاستيراد.

**احتياط مهم:** قبل الاختبار الميداني يُستحسن تصدير نسخة احتياطية خارج المتصفح. تفريغ بيانات المتصفح يحذف الأفكار المحلية، ولا يحل وجود سلة المهملات دون نسخة احتياطية مشكلة فقدان الجهاز أو حذف بيانات المتصفح.
